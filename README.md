# 🚌 Rotas Bus

App de gravação de rotas com mapa, feito em Flutter.

## ✅ Funcionalidades
‑ 📍 Gravação automática por GPS
‑ ✍️ Gravação manual tocando no mapa
‑ 📂 Importação de rotas GPX
‑ 👁️ Visualizar rotas salvas
‑ 🗑️ Apagar rotas
‑ 🎨 Tema escuro

## 🚀 Gerar APK no GitHub
O APK é criado automaticamente pelo GitHub Actions.
1. Crie uma chave do Google Maps e adicione como segredo no repositório:
   ‑ Nome: `GOOGLE_MAPS_API_KEY`
   ‑ Valor: sua chave da API

## 📱 Como usar
‑ **Gravar**: toque em GRAVAR para começar a registrar
‑ **Manual**: toque em GRAVAR MANUAL e depois toque no mapa para marcar pontos
‑ **Rotas Salvas**: ver suas rotas e importar arquivos GPX
‑ **Importar**: botão de upload no topo da lista de rotas

## 🔑 Aviso
Coloque sua chave do Google Maps no segredo do GitHub antes de enviar o código.
